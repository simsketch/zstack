# zStack

zStack is a harness-agnostic agent skill for engineering work. It routes each task, such as a multi-file
change, a bug with an unknown cause, performance work, a review or a PR that needs landing, to a short
playbook, names the working principles it applies, and ships small bash and Python scripts for checks,
evidence and handoffs. One skills tree serves Claude Code, Codex, Cursor, Gemini CLI, OpenCode and Pi.

Quick install from a clone: `./install.sh` links `skills/zstack` into `~/.agents/skills/` and
`~/.claude/skills/`. Restart your agent session afterwards.
